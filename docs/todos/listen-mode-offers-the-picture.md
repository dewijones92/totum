# In Listen mode, offer the picture when you start something that has one

Dewi, 2026-10-23: *"if I'm in listen-only mode and I play like a video or a torrent … prompt me, do you want to switch
to video mode?"* Decided: **only when you start it yourself** (a tap, a search result, a torrent), never on auto-advance;
a **strip over the mini player for ~8 s**, "🎬 … has a picture" with **Watch** (switches the mode to video, as the
player's button does) and **Keep listening** (or ignore it). Anything with a picture (ADR 70 `Picture`), never music.

Done 2026-10-23: [ADR 84](../adr/0084-listen-offers-the-picture-when-you-start-it.md).
