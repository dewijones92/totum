# Choose audio, video (and quality) or both when downloading

On download, a sheet: 🎧 Audio · 🎬 Video (best / 1080p / 720p / 480p) · Both, with a "remember for next time" tick; long-press always asks again (Dewi's choice). Today the choice is audio or full video, quality is always best.

Decided 2026-10-23 (Dewi): **no "Both"** (a video file plays with the picture off in Listen, so a second sound copy
only costs space); the picker is 🎧 Sound · 🎬 Video (Best by default, 1080p, 720p, 480p) with "remember for next
time"; long-press asks again. Fix the upgrade path first (`download-upgrade-keeps-the-old-copy.md`).
