# Quick alarm from the alarm notification

Dewi, 2026-10-30: *"I have a meeting in like 30 minutes … 3 minutes before the meeting, I want an alarm to set off so
that … I run up and downstairs 5 times … at the moment I have to set an alarm name, etc. … I click … the alarm banner
… and then I could bam, really, really quickly. Okay, for 9:26, set an alarm."*

**His answers (AskUserQuestion, 2026-10-30):**
- **Entry:** a ⚡ Quick alarm button on the alarm board notification, opening a small screen straight away, over the
  lock screen too.
- **Time:** the alarm's own time (9:26), not the meeting's.
- **Title:** saved presets ("🏃 Stairs ×5"), one tap; the screen starts on the last one used.
- **Ring:** a full alarm, full screen until dismissed, like the other alarms.
- **Time entry:** the clock dial, on screen straight away.
- **Presets managed on the quick screen:** long-press to rename or delete, ➕ to add.

A time already gone today means tomorrow (as a one-off's clock does).
