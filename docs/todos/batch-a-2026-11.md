## How this batch runs (Dewi, 2026-11-06)

- **Code first, tests after**, for this batch only: every item is written, compiled, checked with detekt and the
  existing tests, committed and **pushed as it goes** so Dewi can try it. New tests, emulator looks and TV checks come
  in one testing stretch after the code. A bug fix's test is still proven red, by running it on the commit before the
  fix. If CI's coverage gate blocks a release, that piece's tests are written straight away.
- **An extra soak after phase 2** (the bug fixes touch playback and casting most), as well as the soak at the end.
