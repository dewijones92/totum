# Decisions

Every standing decision, one row each: the choice and a sentence of why. Where a row links an ADR, the ADR is the
authority and the row is its one-line summary; rows with no ADR (decisions made before 2026-10-01) are the only record.
The table lived in `CLAUDE.md` until 2026-11-28 (moved at commit `698933d9`; rows verbatim, ADR links re-based to this folder).

**Search this file, do not read it whole** (`grep -n -i 'gapless' docs/decisions.md`, or by ADR number).

**Adding a decision:** write its ADR in `adr/` and add its row at the end of this table, in the same change as the
code. Changing a decision updates both; reversing one marks the ADR `superseded by NNNN`, writes the new ADR and updates
the row. `CLAUDE.md` gets a line only when every later change has to obey the decision: a seam for its "One seam each"
list, a foundation changed, a hard stop, or a standing rule from Dewi. A feature decision adds nothing there. Row order
is not significant.
